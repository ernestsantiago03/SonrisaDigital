# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público para reportar una vulnerabilidad. Envíala por correo a **ernestsantiago03@gmail.com** con el asunto `[SonrisaDigital] Vulnerabilidad`.

Incluye:
- Descripción del problema y su impacto.
- Pasos para reproducirlo (sin datos reales de pacientes).
- Versión o commit afectado, si lo conoces.

Respuesta esperada: acuse de recibo en 3 días hábiles. Una vez confirmada, se corrige en la rama de desarrollo y se coordina la publicación.

## Datos sensibles

Los datos de pacientes son clínicos. Al probar, usa únicamente datos ficticios. Si encuentras datos reales expuestos, repórtalo igual y no los compartas.

## Versiones con soporte

Solo la rama `main` recibe correcciones de seguridad.
